# "Book Tracker"
Never forget a read again! 
A little portfolio project made with Next.js, Drizzle, Neon, and Claude Code.

# Features
- Add a book with search powered by the OpenLibrary API
- Update the status of a book in your shelf ("want to read," "reading," "finished")
- Assign in-progress or finished books a rating
- Like anything specific? Really hate a character? Add it in the book notes!
